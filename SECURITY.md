# Security policy

## Reporting a vulnerability

Please report a suspected vulnerability privately, through **Report a vulnerability** on this repository's Security tab (GitHub's private vulnerability reporting). Please do not open a public issue or pull request for it.

Say what you found, where, and how to reproduce it. This is a one-person project: you will get an acknowledgement, and a fix as soon as its severity and the time available allow. There is no bounty.

## What is in scope

- The code in this repository.
- The site it runs, <https://degreesofcarbon.syena.io>, and the preview of it.

Not in scope: Cloudflare, GitHub and other services the site relies on (report those to their owners); libraries this code uses (report them upstream, and tell us if we ship a version with a known advisory); load or denial-of-service testing against the site (please do not); social engineering.

## Supported versions

Only the current `main` branch and the site built from it.
